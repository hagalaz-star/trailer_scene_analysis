# trailer_scene_analysis


- 데이터: 영화 예고편 5편(Arrival, Blade Runner 2049, Dune: Part Three, Interstellar, Tenet)
- PySceneDetect로 장면 분할해 만든 키프레임 450장 (영상 파일은 저장소에 포함하지 않음)

- 모델: CLIP ViT-B/32로 이미지·텍스트를 512차원 벡터로 변환

- 검색: FAISS(Inner Product, 정규화 벡터 = 코사인 유사도)
  - 이미지 → 이미지, 영화 간 유사 장면, 텍스트 → 이미지 검색
  - `max_per_movie`로 한 영화에 결과가 몰리는 것 제한

- 시각화: UMAP + Gradio로 임베딩 분포 확인

### 중간 결론
- CLIP은 장면의 전체 분위기와 색감은 잘 잡지만, 작은 객체, 객체 간 관계, 행동은 놓치는 경향이 있었습니다
- 이미지 한 장을 벡터 하나로 압축하기 때문에 세부 정보와 관계가 약해지는 것으로 해석했습니다

### 한계
- 쿼리 7개에 대한 1인 정성 평가이며, Recall@K 같은 정량 지표가 없습니다
- 장면 분할로 뽑은 키프레임의 품질이 검색 결과에 영향을 줍니다
- GroundingDINO를 이용한 객체 단위 비교는 미완성입니다




본 프로젝트는 영화 트레일러에서 추출한 키프레임을 대상으로 CLIP 기반 텍스트-장면 검색을 수행하고, 검색 결과를 Good / Partial / Fail 기준으로 평가한다.

특히 성공 사례보다 Partial/Fail 사례에 초점을 맞추어, 모델이 객체, 공간 관계, 행동, 장면 분위기를 어떤 방식으로 혼동하는지 분석한다.

검색 결과가 특정 영화에 과도하게 편중되는 것을 방지하기 위해 영화당 최대 2개의 키프레임만 출력하도록 제한했다. 따라서 본 결과는 순수 Top-k 유사도 검색이 아니라, 영화 다양성 제약이 적용된 검색 결과이다.
